# 🪶 PROJECTGOMAD

Building worlds — some made of cubes, some on land, and some at sea.

I’m **ProjectGoMad** (aka **diskawrs**) — creator, server tinkerer, and occasional boat refitter trying to keep a balance between tech and real life.

---

## GoMad / GoLive

“GoLive” for me has two meanings:

- **Go live online** — stream, build, script, share.  
- **Go live for real** — get outside, sail, fix, renovate, make.

Some days I’m scripting Denizen for **A Game of Cubes**.  
Other days I’m on **Skellig** (a 1970s Écume de Mer) doing yet another “small” job that’s never small.

---

## Ongoing projects

- 🧱 **[A Game of Cubes](https://agameofcubes.com)** — community-first RPG Minecraft world (Towny, Denizen, MythicMobs).  
- ⚓ **[Skellig — Écume de Mer](https://projectgomad.com/index.php/skellig-ecume-de-mar/)** — 1976 cabin/extended-coachroof version, rolling refit.  
- 🪴 **Townhouse work** — IRL renovation to match the “build → break → improve” mindset.  
- 📡 **[Twitch](https://twitch.com/projectgomad)** — live when I’m not covered in dust.
